Задача: придумать концепт игры‑тренажёра для трейдинга.
Жанр: гибрид Simulation + Puzzle + Card Battler + Narrative Choice + Social.  
Референсы: Duolingo (структура обучения) + [назови 1–2 игры, которые тебе нравятся].
Ключевые элементы:  
– Simulation: игрок управляет своим профилем трейдера, прокачивает навыки.  
– Puzzle: короткие задачи на распознавание паттернов рынка.  
– Card Battler: карты — факторы рынка, игрок “сражается” с сценариями.  
– Narrative Choice: истории реальных рыночных событий с выбором действий.  
– Social: лиги, турниры, рейтинги по качеству решений (не по PnL).
Что НЕ должно быть:  
– Торговый терминал, ордера, угадывание направления цены.
Опиши: core loop, прогрессию, мета‑игру, как встроено обучение, как избегается превращение в “терминал”.»
